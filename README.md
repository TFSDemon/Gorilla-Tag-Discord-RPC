GorillaTagDiscordRPC is a BepInEx mod for Gorilla Tag that adds a custom Discord Rich Presence for the game. It displays the room code, public/private status, game mode, and player counts in real time, featuring an in-game toggle GUI by pressing the H key.

Now Shows Map, Queue, Tag or Untagged or other game mode specific state 

Also Has Quest Support Using Friend Machine (must be only account added) Very Limited Tho
